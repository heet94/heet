Screenshots
===========

This project contains two placeholder SVG screenshots in the `screenshots/` folder. Replace them with real screenshots captured from your local run if you prefer.

Files:

- `screenshots/home_screenshot.svg` — placeholder dashboard/home view
- `screenshots/books_index_screenshot.svg` — placeholder books index view

How to add real screenshots
1. Run the application locally:

   dotnet run

2. Open the app in a browser and use the Windows Snipping Tool / Print Screen to capture the pages.
3. Save images to `screenshots/` (PNG/JPG/SVG). Example filenames:

   screenshots/home.png
   screenshots/books_index.png

4. Commit and push your images:

   git add screenshots/*
   git commit -m "Add real screenshots"
   git push

If you want, I can also create a small Playwright/Headless script to capture screenshots automatically — tell me if you'd like that and I will add the script and instructions.
